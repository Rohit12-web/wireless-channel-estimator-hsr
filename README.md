# Mobility-Aware Channel Estimation for IRS-Assisted High-Speed Railways

Reproducibility repository for the physics-guided and uncertainty-aware
future effective-channel prediction framework developed for a single-IRS-assisted
high-speed railway (HSR) MIMO link.

Only the final publication pipeline is retained. Development versions, smoke-test
runs, generated model checkpoints, temporary figures, and older exploratory
implementations are intentionally excluded so that the DOI archive maps cleanly
to the manuscript methodology.

## Main implementation

`src/publication_pipeline_v6_transactions_final.py`

The pipeline implements:

- the effective channel `H_eff = H_d + H_r Phi G`;
- continuous HSR motion with geometry-dependent Doppler evolution;
- orthogonal MIMO pilots and LS channel initialization;
- matched/mismatched LMMSE and temporal LMMSE references;
- spatial learning baselines and temporal CNN-BiLSTM/GRU-ODE-inspired baselines;
- physics-guided signed-Doppler/Jakes future-channel prediction;
- condition-aware BiLSTM residual refinement;
- heteroscedastic predictive uncertainty;
- adaptive pilot-selection evaluation;
- prediction-aware IRS-control evaluation;
- NMSE, channel-aging, mobility, BER, spectral-efficiency, robustness,
  ablation, uncertainty, and complexity evaluations.

## Installation

Python 3.10+ is recommended.

```bash
pip install -r requirements.txt
```

## Quick implementation check

```bash
python src/publication_pipeline_v6_transactions_final.py --mode smoke
```

## Publication-profile run

```bash
python src/publication_pipeline_v6_transactions_final.py     --mode publication     --output-dir rohitash_ieee_access_results
```

The publication configuration uses five principal seeds by default. The complete
publication profile is computationally intensive and is intended for a GPU-enabled
TensorFlow environment.

## Data

No external dataset is required. Channel observations are generated by the
simulation model implemented in the publication pipeline. See `data/README.md`.

## Results

Generated results are not bundled with this source release because the uploaded
working directory contained multiple historical, smoke-test, and reduced-budget
result sets. This prevents accidental mixing of nonfinal results with the DOI
release. After the final manuscript run is frozen, its exact CSV/JSON outputs and
paper figures may be added under `results/` in a tagged release.

## Reproducibility note

The paper should report only results generated with the configuration actually
used for the corresponding figure/table. In particular, seed counts and
confidence-interval statements should match the executed run.
