# Results

This directory is reserved for the **final frozen manuscript outputs only**.

Recommended contents for the archival release:

- final CSV files used to plot manuscript figures;
- final JSON experiment metadata;
- final complexity table output;
- final figures reproduced from those CSV/JSON files.

Do not mix smoke-test, reduced-budget, older V4/V5, or exploratory results with
the DOI release.

The original working archive contained multiple historical result sets, so none
are copied here automatically. Add the exact final run after the manuscript
configuration and seed count are frozen.
